Custom commands — type the prefix in any chat to get the reply

How it works
1. Click + Add command. Give it a trigger that starts with a symbol — .price, !rules, /menu2.
2. Write the reply. Placeholders: {name} = sender's WhatsApp name, {time} = current UTC time.
3. Anyone texting the bot that exact prefix gets the reply. Test it by sending .price yourself.
